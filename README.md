
# Customer Behavior Analytics

## Overview
This project analyzes customer purchasing behavior using Python, 
SQL Server, and Power BI.
The goal was to clean and transform the data, analyze customer and 
product behavior, and build an interactive dashboard to identify 
useful business insights.

## Tools
- Python / Pandas
- SQL Server
- Power BI
- GitHub

## Project Workflow
### 1. Data Cleaning — Python
Used Pandas to:
- Handle missing values
- Rename columns
- Create age groups
- Create purchase frequency categories
- Prepare the dataset for SQL analysis

### 2. Data Analysis — SQL Server
Used SQL Server to analyze:
- Customer purchasing behavior
- Product performance
- Category performance
- Average product ratings
- Customer segmentation
- Top products within each category

SQL techniques included:
- CTEs
- Window functions
- `ROW_NUMBER()`
- `GROUP BY`
- Aggregate functions
- `CASE` statements

### 3. Dashboard — Power BI
Created an interactive dashboard to analyze:
- Customer demographics
- Purchase behavior
- Product categories
- Ratings
- Subscription status
- Purchasing frequency
